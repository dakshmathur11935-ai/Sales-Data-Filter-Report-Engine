# Sales Data Filter & Report Engine

## About the Project

This project analyzes sales data of 10 stores over 12 months using Python, NumPy, and Matplotlib. It helps calculate total sales, filter sales data, compare performance, and visualize monthly sales.

## Technologies Used

* Python
* NumPy
* Matplotlib
* Google Colab

## Features

* Generates sales data for 10 stores and 12 months.
* Calculates total monthly and store-wise sales.
* Analyzes quarterly sales.
* Filters sales above or below specific values.
* Finds stores with below-average sales.
* Identifies the top 3 sales months.
* Checks monthly sales targets.
* Displays a bar graph of monthly sales.

## How It Works

1. Creates sample sales data using NumPy.
2. Calculates monthly, store-wise, and quarterly sales.
3. Filters data using conditions.
4. Compares sales with average values and targets.
5. Displays a monthly sales report using a bar graph.

## How to Run

1. Open the project in Google Colab.
2. Run each code cell in order.
3. View the sales analysis and graph.

## Output

* Monthly sales report
* Store-wise sales report
* Quarterly sales analysis
* Filtered sales data
* Top 3 sales months
* Sales target report
* Monthly sales bar graph
